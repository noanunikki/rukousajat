# Rukousajat – islamilaiset rukousajat

Käyttö suoraan: https://noanunikki.github.io/rukousajat/

Yhden tiedoston (`index.html`) rukousaikasovellus. Avaa tiedosto selaimessa – ei asennusta eikä palvelinta.

- Rukousajat (Imsak, Fajr, auringonnousu, Dhuhr/Jumu'ah, Asr, Maghrib, Isha, keskiyö, yön viimeinen kolmannes)
- Tähtitieteellinen laskenta laitteessa (Meeus), verrattu Aladhan.com-palveluun (±1 min, Asr korkeilla leveysasteilla enemmän)
- 18 laskentamenetelmää, Hanafi/Shafi'i-Asr, korkean leveysasteen säännöt (Suomi!), minuuttikorjaukset
- GPS, kaupunkihaku, aikavyöhyke ja kesäaika automaattisesti
- Hijri-kalenteri (Umm al-Qura), juhlapäivät, paastokortti, Ramadan-laskuri
- Qibla-kompassi, tasbih-laskuri, ilmoitukset ja oma adhan-ääni
- Suomi / English, vaalea / tumma teema, kuukausitaulukko (CSV, tulostus)

**Huomio:** rukousaikojen ja Ramadanin alun vahvistaminen kuuluu aina paikalliselle pätevälle yhteisölle tai moskeijalle. Ilmoitukset toimivat vain, kun sivu on auki.
